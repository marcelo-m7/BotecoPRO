# Archived intermediary API design

The former `botecopro_api` addon, OpenAPI contract and `/api/v1/botecopro/*`
documentation described a Flutter → BotecoPRO API → Odoo architecture. They
were never the required production path and are superseded by direct Odoo
JSON-2 calls. The implementation is removed from the active tree; Git history
retains the original experiment for reference.
